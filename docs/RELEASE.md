# Version 0.1.0

Local personal records with audited SQLite, schema-driven imports, masked REST and MCP tools.

Local verification: 34 tests passed; 92% measured coverage; Ruff lint and formatting checks passed. README quick start was exercised with fictional data.

## Known limitations

Text-based PDF table extraction only, with no OCR. Local files are not encrypted; the app is intended for one trusted user. Imports run through the CLI; the browser supports browsing and editing. One upstream TestClient deprecation warning remains.

See README and AGENTS.md for installation, configuration, machine-readable CLI/MCP interfaces and operational boundaries.
